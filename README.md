# قالب "تحبيني؟" — نسخة سارة

ملفات HTML/CSS/JS ثابتة جاهزة لـ GitHub Pages.

## النشر
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد (index.html, yes_page.html, styles.css, script.js, config.js).
2. Settings → Pages → Source: Deploy from a branch → main / root.
3. افتح الرابط `https://<username>.github.io/<repo>/`.

## التخصيص
كل النصوص والصور في ملف `config.js` فقط: الاسم، السؤال، رسائل زر "لا"، الصور المتحركة، وصفحة الموافقة.
